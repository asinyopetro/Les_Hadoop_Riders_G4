# Comment pousser ta partie (2 minutes)

1. Accepte l’invitation : https://github.com/asinyopetro/Les_Hadoop_Riders_G4/invitations
2. Ouvre un terminal :

```powershell
git clone https://github.com/asinyopetro/Les_Hadoop_Riders_G4.git
cd Les_Hadoop_Riders_G4
git pull
```

3. Ouvre **ton** fichier dans `contributions/` (celui à ton nom).
4. Remplace la ligne `date : ________` par la date d’aujourd’hui et coche `[x]`.
5. Commit et push **avec ton compte GitHub** :

```powershell
git add contributions/
git commit -m "docs: validation presentation [TON PRENOM]"
git push
```

Si GitHub demande de te connecter, utilise **ton** username.
